# Hoja de vida — Santiago Prieto Castellanos

Página web de mi hoja de vida (ES/EN). Todo está en `index.html`.

## Cómo actualizarla
- **Textos en español e inglés:** objeto `T` dentro del `<script>` (claves `es` y `en`).
- **Experiencia:** arreglo `JOBS` (cargo, empresa, fechas y viñetas en ambos idiomas).
- **Reportes y portafolio CNS:** arreglos `REPORTS` y `BRANDS`.
- **Herramientas:** arreglo `TOOLS` (nivel 100 = Avanzado, 75 = Intermedio-avanzado).
- **Proyectos:** arreglo `PROJ`. **Formación:** sección `#formacion` en el HTML + claves `edu*` en `T`.

Para editar desde el navegador: abre `index.html` en GitHub → ícono del lápiz → "Commit changes". La página publicada se actualiza en 1–2 minutos.
